CSA47 - DEEP LEARNING | UNIT 4 (CO4)
VS Code Python programs and sample outputs

Included visible experiments: 49, 50, and 52-64.
Experiment 51 was not visible in the screenshots and is intentionally not guessed.

FOLDER STRUCTURE
programs/  -> Python source files (.py), plus common.py helper
outputs/   -> captured sample outputs (.txt)

HOW TO RUN IN VS CODE
1. Extract this ZIP file.
2. Open the extracted CSA47_Unit4_CO4_VSCode folder in VS Code.
3. Open Terminal > New Terminal.
4. Install NumPy once:
       py -m pip install numpy
5. Run one experiment at a time, for example:
       py programs/exp_49.py
   Replace 49 with the experiment number.

Most programs use small synthetic/demo data so they run quickly on a normal laptop.
For real research results, replace the demonstration data with the dataset specified by your faculty.
